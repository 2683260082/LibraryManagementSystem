## 1. 安装

### 1.1 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 及以上（macOS / Linux 同样适用） |
| Python | **3.8 及以上**（本项目在 3.11.9 上验证通过） |
| 浏览器 | 任意现代浏览器 |
| 数据库 | **无需安装**（SQLite 随 Python 内置） |

### 1.2 安装 Python

1. 打开 <https://www.python.org/downloads/> 下载最新版本
2. 运行安装程序，**务必勾选底部的 `Add Python to PATH`**（这一步最关键）
3. 点击 `Install Now`，等待完成

**验证安装**：打开命令提示符（`Win + R` 输入 `cmd` 回车），执行：

```bash
python --version
```

显示 `Python 3.11.x` 即成功。

> **如果提示"不是内部或外部命令"**：说明安装时漏勾了 `Add Python to PATH`。
> 重新运行 Python 安装程序 → 选择 `Modify` → 勾选 `Add Python to PATH` → 完成。

### 1.3 安装项目依赖

项目**只依赖 Flask 一项**。有两种方式：

| 方式 | 操作 | 说明 |
|------|------|------|
| **自动**（推荐） | 双击 `01-【双击开始】.bat` | 脚本检测到缺少 Flask 时会自动执行安装 |
| 手动 | 命令行执行 `pip install -r requirements.txt` | 在 `03-项目源码` 目录下执行 |

下载缓慢时可换用国内镜像：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 2. 启动与停止

### 2.1 启动

```
双击根目录的  01-【双击开始】.bat
```

脚本会依次完成：

| 步骤 | 动作 |
|------|------|
| 1 | 检查 Python 是否可用 |
| 2 | 检查 Flask，缺失则自动安装 |
| 3 | 进入 `03-项目源码` 目录并启动服务 |
| 4 | 约 5 秒后自动打开浏览器 |

启动成功后窗口会显示：

```
==================================================
图书管理系统已启动
访问地址: http://127.0.0.1:5000
管理员账号: admin / admin123
读者账号:   reader / reader123
==================================================
```

### 2.2 访问系统

浏览器会自动打开，若未打开则手动访问：

```
http://127.0.0.1:5000
```

### 2.3 停止服务

| 方式 | 操作 |
|------|------|
| 关闭窗口 | 直接关闭那个黑色命令行窗口 |
| 快捷键 | 在该窗口按 `Ctrl + C` |

> **重要**：服务运行期间那个窗口不能关，关了系统就无法访问了。

## 3. 账号

| 角色 | 用户名 | 密码 | 能做什么 |
|------|--------|------|----------|
| 管理员 | `admin` | `admin123` | 全部功能 + 图书/读者管理 + 全馆统计 |
| 读者 | `reader` | `reader123` | 检索、借书、还书、查看自己的借阅 |

这两个账号在**登录页面上也直接写着**，忘了随时可以看。

> 管理员账号**不开放注册**——注册页创建的都是读者账号，无法自行提权。

## 4. 读者功能操作

### 4.1 注册

1. 打开登录页，点击 **「立即注册」**
2. 填写：
   - **用户名**（必填）：3–30 位，只能用字母、数字、下划线
   - **姓名**（必填）：真实姓名
   - **手机号**（选填）：11 位数字
   - **密码**（必填）：至少 6 位
3. 点击 **「注 册」** → 自动跳回登录页

| 常见提示 | 原因 |
|----------|------|
| 用户名已存在 | 该用户名被占用了，换一个 |
| 用户名只能包含字母、数字、下划线 | 含空格、中文或特殊符号 |
| 密码至少 6 位 | 密码太短 |
| 手机号格式不正确 | 不是 11 位或不以 1 开头 |

### 4.2 检索图书

1. 顶部导航点击 **「图书检索」**
2. 两种查询方式可单独或组合使用：
   - **关键词搜索**：输入书名、作者或 ISBN 的一部分（模糊匹配）
   - **分类筛选**：下拉框选择分类（计算机 / 历史 / 经济 / 文学 / 科幻）
3. 点击 **「搜 索」**；点击 **「重置」** 清除条件

**库存列显示 `可借 / 总数`**，例如 `7 / 7` 表示 7 本全部可借。
数字变红表示已借完。

### 4.3 借书

1. 在图书列表中找到目标图书
2. 点击 **「借阅」** 按钮
3. 成功后显示：`借阅成功！请于 2026-12-08 前归还`

**借阅规则**

| 规则 | 说明 |
|------|------|
| 借阅期限 | **60 天** |
| 库存不足 | 按钮显示灰色「库存不足」，无法点击 |
| 重复借阅 | 同一本书未归还前不能再借第二本 |
| 每人限制 | 无数量上限，但同一本书只能借一本 |

借阅成功后会自动跳转到 **「我的借阅」** 页面。

### 4.4 还书

1. 顶部导航点击 **「我的借阅」**
2. 找到要归还的记录，点击 **「归还」**
3. 确认弹窗中点「确定」

**逾期费计算**

| 情况 | 违约金 |
|------|--------|
| 按时或提前归还 | 0 元 |
| 逾期 | **每天 0.1 元**，归还时自动结算 |

逾期未还期间，「我的借阅」页面会：
- 状态显示红色 **「已逾期」**
- 整行**淡黄底色高亮**
- 金额列显示实时增长的 **「应计」** 违约金（虚估，归还时才正式结算）

### 4.5 查看我的借阅

「我的借阅」页按时间倒序列出全部记录，每条包含：

| 列 | 含义 |
|----|------|
| 书名 / 作者 | 借的什么书 |
| 借阅日期 / 应还日期 | 时间节点 |
| 归还日期 | `—` 表示还没还 |
| 逾期费 | 已还显示实收金额，未还逾期显示应计金额 |
| 状态 | 蓝色「借阅中」/ 红色「已逾期」/ 绿色「已归还」 |
| 操作 | 未归还时显示「归还」按钮 |

## 5. 管理员功能操作

以 `admin / admin123` 登录后，顶部导航会多出 **「读者管理」** 和 **「借阅记录」** 两项。

### 5.1 控制台

登录后首屏即控制台，包含：

| 统计卡 | 含义 |
|--------|------|
| 图书种类 | 不同书目的数量 |
| 馆藏总量 | 所有书的册数总和 |
| 当前借出 | 此刻在借未还的数量 |
| 注册读者 | 有效（未注销）读者数 |

下方是 **「最新借阅动态」**（全馆最近 8 条）。

### 5.2 新增图书

1. 「图书检索」页点击右上角 **「+ 新增图书」**
2. 填写：

| 字段 | 必填 | 规则 |
|------|------|------|
| ISBN | 否 | 最多 20 字符 |
| **书名** | **是** | 最多 100 字符 |
| 作者 / 出版社 / 分类 | 否 | 最多 100 字符 |
| 价格 | 否 | 非负数，最多两位小数 |
| **馆藏总数** | **是** | 1 – 100000 的整数 |

3. 点击 **「保 存」**

> **可借册数无需填写**——由系统根据实际借阅情况自动计算，页面上有说明文字提示。

校验失败时**已填内容会保留**，改好后重新提交即可，不会白填。

### 5.3 编辑图书

1. 图书列表中点击 **「编辑」**
2. 修改字段 → 点击 **「保 存」**

**重要规则**：馆藏总数**不能小于当前未归还的数量**。

例如某书借出 2 册，若把总数改成 1，会提示：
`该书尚有 2 册未归还, 馆藏总数不能小于 2`

保存后可借数会按 `新总数 − 已借出数` 自动重算。

### 5.4 删除图书

| 情况 | 表现 |
|------|------|
| 该书**从未被借过** | 删除按钮正常，点击后有确认弹窗 |
| 该书**有过借阅记录**（含已归还） | 按钮**灰色禁用**，悬停提示"该书已有 N 条借阅记录，为保证凭证完整无法删除" |

> **为什么不让删？** 借阅记录是读者的借阅凭证，删书会让这些记录指向不存在的图书，
> 造成数据不一致。系统选择保留凭证。

### 5.5 读者管理与注销

1. 顶部导航点击 **「读者管理」**
2. 列表显示每位读者的用户名、姓名、手机号、注册时间、**当前在借数量**
3. 点击 **「注 销」**：

| 情况 | 结果 |
|------|------|
| 该读者有未还图书 | 按钮**禁用**，悬停提示"有未还图书，无法注销" |
| 无未还图书 | 注销成功，提示"读者已注销（历史借阅记录保留）" |

**注销 ≠ 删除**：

| 方面 | 结果 |
|------|------|
| 能否登录 | ❌ 不能 |
| 是否还在列表 | ❌ 不再显示 |
| 借阅历史 | ✅ **完整保留**，在借阅记录页仍可查到 |

### 5.6 借阅记录查询

1. 顶部导航点击 **「借阅记录」**
2. 筛选方式：

| 控件 | 选项 |
|------|------|
| 关键词 | 输入书名或读者姓名（模糊匹配） |
| 状态下拉 | 全部状态 / 仅看在借 / 仅看逾期 |

3. 点击 **「筛 选」**，**「重置」** 清除条件

**逾期记录整行淡黄底色高亮**，状态列显示红色「已逾期」。

## 6. 分页操作

图书检索、读者管理、我的借阅、借阅记录四个列表都支持分页：

```
        ← 上一页      第 1 / 4 页 · 共 38 条      下一页 →
```

| 参数 | 默认 | 可调范围 |
|------|------|----------|
| 每页条数 | 10 | 1 – 100 |

翻页时会**自动保留当前的搜索与筛选条件**，不必重新输入。

> 需要一次性看更多时，可在地址栏 URL 后追加 `&per_page=50`，例如
> `http://127.0.0.1:5000/books?per_page=50`。

## 7. 数据管理

### 7.1 恢复初始状态

数据改乱了、想从头演示？只需两步：

```
1. 关闭服务窗口
2. 删除  03-项目源码\library.db
3. 重新双击  01-【双击开始】.bat
```

系统会自动重建数据库，写入 8 本演示图书和 2 个演示账号。

### 7.2 备份

直接复制 `03-项目源码\library.db` 文件即可，整个数据库就是这一个文件。

### 7.3 查看/修改数据

用任意 SQLite 客户端打开 `library.db`：

- DB Browser for SQLite（推荐，图形界面）
- 命令行：`sqlite3 03-项目源码/library.db`

**重置管理员密码**（忘记密码时）：

```sql
-- 在 SQLite 客户端中执行（需先安装 werkzeug，或直接删库重建更省事）
UPDATE users SET password = '<新哈希值>' WHERE username = 'admin';
```

> 更简单的方式是直接删除 `library.db` 重建，见 7.1。

## 8. 运行测试

```bash
# 进入源码目录
cd 03-项目源码

# 方式一：单元测试（40 个用例，无需启动服务）
python -m unittest discover -s unit_test -t .

# 方式二：端到端测试（36 项断言，需先启动服务）
python smoke_test.py
```

**测试是安全的**：单元测试用独立临时数据库，端到端测试结束自动清理临时数据，
两种方式**都不会破坏你的业务数据**。

## 9. 常见问题

| 现象 | 原因 | 解决办法 |
|------|------|----------|
| 双击 .bat 闪退 | Python 未安装 | 安装 Python 并勾选 `Add Python to PATH` |
| `不是内部或外部命令` | Python 未加入 PATH | 重跑安装程序 → Modify → 勾选 PATH |
| `No module named 'flask'` | 缺少依赖 | `pip install -r requirements.txt` |
| `Address already in use` | 端口被占用 | 关掉已有服务窗口，或改 `app.py` 末行 `port=5001` |
| 页面空白 / 样式乱 | 浏览器缓存 | 按 `Ctrl + F5` 强制刷新 |
| 页面打不开 | 服务未启动完成 | 等几秒再按 `F5` 刷新 |
| 提示"找不到源码目录" | 单独复制了 .bat | 必须让 .bat 和 `03-项目源码` 在同一层 |
| 中文显示为乱码 | 控制台编码问题 | 使用 `01-【双击开始】.bat` 启动（已内置 UTF-8 设置） |
| 数据不对 / 想重来 | — | 删除 `library.db` 重启，见 7.1 |
