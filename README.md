# 图书管理系统 · 课程设计

基于 **Flask + SQLite** 的图书管理系统课程设计项目，定位为可独立运行的完整演示系统：包含配套课程设计文档、可运行源码与测试（单元测试 + 端到端冒烟测试）。

## 功能特性

- **双角色体系**：管理员 / 读者，基于会话的登录与权限隔离
- **图书管理**：图书增删改查、分页浏览、关键词检索
- **读者管理**：读者注册审核、注销（软删除，保留历史借阅凭证）
- **借阅管理**：借阅 / 归还、逾期违约金计算、借阅记录查询
- **仪表盘**：馆藏与借阅情况统计概览
- **业务保障**：库存扣减采用"条件更新 + 事务"防并发超借；图书删除要求零借阅记录，避免孤儿数据

## 快速开始

环境要求：Python 3.8+（依赖仅 Flask，SQLite 由标准库提供）。

**方式一：双击启动（Windows）**

双击根目录的 `01-【双击开始】.bat`，会自动检查依赖并打开浏览器。

**方式二：命令行**

```bash
cd 03-项目源码
pip install -r requirements.txt
python app.py
```

启动后访问 <http://127.0.0.1:5000>，首次运行自动创建数据库并写入演示数据。

## 运行测试

```bash
cd 03-项目源码

# 单元测试（使用 Flask 测试客户端，无需启动服务）
python -m unittest discover -s unit_test -t .

# 冒烟测试（另开一个终端，先启动 python app.py 再执行）
python smoke_test.py
```

冒烟测试会自行创建临时数据并在结束时清理，不影响 `library.db` 中的演示数据。

## 设计说明

- 会话密钥使用固定值，便于教学演示重启后登录态不失效；如上生产须改为环境变量读取随机密钥。
- 借阅期限 60 天，逾期违约金 0.1 元/天，列表分页每页 10 条，业务参数集中在 `app.py` 顶部统一管理。
- 读者注销为软删除（仅置 `status` 字段），保留历史借阅记录作为凭证。
