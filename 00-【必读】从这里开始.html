1这是一个什么项目

先用 30 秒搞清楚手上拿的是什么东西。

一个功能完整、可以真正跑起来的图书馆借阅管理系统。不是只有几个静态页面的壳子， 而是包含账号体系、权限控制、图书增删改查、借还业务、逾期计费、分页检索、单元测试的完整工程。

一句话概括：用 Python 的 Flask 框架 + SQLite 数据库实现，不需要额外安装数据库软件， 装一个 Python 就能跑。所有数据保存在 03-项目源码\library.db 文件中。
类别包含内容
读者功能 注册 / 登录、图书检索（按书名·作者·ISBN 搜索 + 分类筛选）、借书、还书、查看我的借阅、逾期违约金计算
管理员功能 读者的全部功能 + 图书新增·编辑·删除、读者管理、全馆借阅记录查询（可按状态筛选）、首页统计面板
工程配套 40 个单元测试、36 项端到端验证、一键启动脚本、完整课程设计文档

5常见问题

点一下展开答案。

双击【双击开始】.bat 闪退 / 提示"不是内部或外部命令"
说明 Python 没装，或者安装时没有勾选 Add Python to PATH。
解决：重新运行 Python 安装程序 → 选择 Modify → 勾选 Add Python to PATH → 完成。
验证：在命令行输入 python --version 能显示版本号就说明好了。
提示"ModuleNotFoundError: No module named 'flask'"
缺少 Flask 依赖。运行一次 pip install -r requirements.txt 即可。
如果下载慢，用国内镜像：pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
提示"Address already in use"或端口被占用
说明 5000 端口已有服务在跑（可能你之前启动过一个没关）。
方法一：关掉已有的黑窗口；方法二：改端口——打开 03-项目源码\app.py， 把最后一行的 port=5000 改成 port=5001，再重新启动。
打开页面是空白的，或者样式乱了
浏览器缓存了旧的样式文件。按 Ctrl + F5 强制刷新即可。
忘记管理员密码 / 想把数据恢复成初始状态
直接删除 03-项目源码\library.db 文件，然后重新启动。 系统会自动重建数据库，并写入 8 本演示图书和 2 个演示账号。
怎么运行测试？
在项目目录下打开命令行，先进入源码目录再执行：

cd 03-项目源码

python -m unittest discover -s unit_test -t .  →  40 个单元测试
python smoke_test.py  →  36 项端到端验证（需先启动服务）

测试使用独立的临时数据库，不会影响你的业务数据。

6答辩可能会问到的点

提前准备好这几条，被追问也答得上。

问题要点
为什么用 SQLite？ 零配置、单文件即数据库、无需单独安装服务，适合课程设计场景；切换到 MySQL 只需改连接方式，SQL 基本通用。
怎么防止超借（借空）？ 借书用条件更新：UPDATE ... SET available = available - 1 WHERE available > 0， 由数据库保证原子性，再用 rowcount 判断是否扣减成功。并发下也只有一人成功。
怎么防止 SQL 注入？ 所有 SQL 一律使用参数占位符 ? 传值，用户输入永不拼接进 SQL 字符串。
密码怎么存的？ 用 Werkzeug 的 generate_password_hash 做哈希加盐存储，数据库中不存在明文密码。
权限怎么控制？ login_required 和 admin_required 两个装饰器， 结合 session 中的角色判断；读者访问管理页会被拦截并跳转。
删除读者为什么是"软删除"？ 借阅记录是业务凭证，注销只把 status 标记为 deleted， 历史记录完整保留、可追溯，避免数据丢失。
逾期怎么判定？ 由 SQL 的 julianday() 函数计算日期差，不在模板里做字符串日期比较， 避免日期格式一变判断就出错。
